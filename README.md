# 🎤 Friday AI Assistant

Friday AI Assistant is a Python-based desktop voice assistant powered by **Google Gemini AI**. It uses **Speech Recognition** for voice input, **Edge-TTS** for natural voice synthesis, and **Pygame** for audio playback. Friday can answer questions, open applications and websites, provide system information, and interact with users through voice.

---

## ✨ Features

- 🤖 Google Gemini AI Integration
- 🎤 Speech Recognition
- 🗣️ Natural Voice using Edge-TTS
- 🔊 Audio Playback with Pygame
- ⌨️ Push-to-Talk (Press **SPACE** to speak)
- 💬 Conversation Memory
- 🌐 Open Websites
- 📂 Open Applications
- 💻 System Information
  - CPU Usage
  - RAM Usage
  - Disk Usage
- 🎨 Typing Animation
- 🖥️ Clean Terminal Interface
- 📁 Modular Project Structure

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/pnharishkumaran-cell/Friday-AI-Assistant.git
```

### 2. Go to the Project Folder

```bash
cd Friday-AI-Assistant
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Create a `.env` File

Add your Gemini API key:

```env
GOOGLE_API_KEY=YOUR_API_KEY
```

### 5. Run the Project

```bash
python main.py
```

## 🎮 How to Use

1. Run the program.
2. Press **SPACE** to activate the microphone.
3. Speak your command.
4. Friday listens, processes your request using Gemini AI, and responds with both voice and text.
